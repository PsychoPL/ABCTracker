# ABC Tracker

Suivi comportemental ABA (fiches ABC) et grille douleur GED-DI modifiée TSA.

- Application 100 % locale : aucune donnée n'est envoyée sur internet (connexions réseau bloquées).
- Les données saisies restent chiffrées sur chaque appareil ; ce dépôt ne contient que le code.

Installer sur téléphone : ouvrir https://psychopl.github.io/ABCTracker/ dans Chrome, menu ⋮ → « Installer l'application ».
